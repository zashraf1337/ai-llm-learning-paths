AI / LLM Learning Paths

A practical, project-first guide across seven tracks — Foundations, Red-teaming / LLM security, AI Engineer (agentic apps), Coding Agents, Building & fine-tuning models, Infra & MLOps, and AI researcher — for anyone moving into AI/LLM work. Every resource lists the goal, what you build, cost and time, and an honest read on how useful it is. Each track also has prove-it projects. Career and demand notes are general observations worth checking against current job postings. Progress is saved in your browser where supported.

Use each course's status pill (To do → Doing → Done) to track progress — it's saved in your browser via localStorage where supported; some embedded viewers don't persist it.

How to read the ratings. "Fit" reflects how central a resource is within its track — Start here and Core first, Situational only if you need that specific thing. It is not a measure of quality: a resource can be world-class and still "Situational" for a given goal. "The honest take" flags caveats — dated material, prerequisites, hype vs. substance.

Careers & demand. Notes about hiring, "fit," and demand are general observations from public sources, not guarantees. Validate against current job postings in your region and role before making decisions.

Cost & accuracy. Prices were checked on official pages in Aug 2026 and change often — reconfirm before paying. Notably: DeepLearning.AI short-course videos are free, but hands-on labs, quizzes, and certificates now require DeepLearning.AI Pro (~$25/mo). Many "free" items are open-source tools or open web resources. The AI Red Teaming (AIRTP+) credential is tiered: exam ~$299, on-demand course + exam ~$1,199, live cohort ~$1,495.

Primary sources: Stanford CS336/CS224n/CS231n, fast.ai, Karpathy (Zero-to-Hero, nanochat), Hugging Face (LLM / Agents / MCP courses, TRL, Ultra-Scale Playbook), DeepLearning.AI, Anthropic Academy, OpenAI (Agents SDK, Responses API, Evals), Google (ADK), LangChain Academy, GPU MODE, Chip Huyen (AI Engineering, Designing ML Systems), Raschka, Maxime Labonne, ARENA / Neel Nanda, Learn Prompting / HackAPrompt, OWASP GenAI Security Project, MITRE ATLAS, NIST AI RMF, SWE-bench, DataTalksClub, and the tool projects' own docs (vLLM, SGLang, Ollama, LiteLLM, Ragas, Inspect, Langfuse, Phoenix, garak, PyRIT, promptfoo). Verify current pricing/enrollment on each provider's site.
